# New features

Sample tasks for trying the features added in 0.2 and 0.3.

## Focus on this task

Right-click one of these and choose "Focus on this task". Or put the cursor on the line and run the command "Kiri Focus Timer: Focus on this task".

- [ ] Outline the newsletter
- [ ] Sort the photo folder

## Planned against spent

Turn on "Add time spent to the task" in settings first. After a block, Kiri adds `[spent:: 25m]` and the Kiri panel shows "Spent 25m of 1h planned".

- [ ] Write the product page [planned:: 1h]
- [ ] Fix the contact form [estimate:: 50m] [spent:: 25m]

Tasks plugin dates stay at the end of the line, in both styles:

- [ ] Draft the invoice text [planned:: 30m] 📅 2026-11-20
- [ ] Plan the team call [planned:: 45m] [due:: 2026-11-21]

## Long breaks

With the default settings every 4th block is followed by a 15 minute break. For a quick test set "Long break every" to 2 and type `5` in the custom minutes box.

## Focus stats

Click "Focus stats" in the Kiri panel. The daily notes in `Daily` already have some log lines, so you should see a streak.

## Try Today (0.3)

Steps (a numbered list, so they are not tasks themselves):

1. Click + next to "Water the plants" and "Reply to Sam" in the Kiri panel (open this note first). Both show a check mark in the list, and Today shows them at the top.
2. Run "Kiri Focus Timer: Add open tasks from this note to Today". Tasks already on Today are not added twice.
3. Drag "Reply to Sam" above "Water the plants". Then use the up and down buttons with Tab and Enter.
4. Turn on "Add time spent to the task", start a 5 minute block, and after a minute or two tick the first task. The block goes on; the task gets `[spent:: ...]` and `[x]`, and the next task is now first.
5. Tick a Today task here in the note instead. It leaves Today.
6. Right-click a task here and choose "Add to Today".
7. With a Kiri account connected, finish a block: a notice shows "+1 kiri" (or a fraction for a short block) and the panel footer shows your total.

- [ ] Book the dentist 📅 2026-11-20
